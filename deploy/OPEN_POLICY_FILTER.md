# 신청 중 정책 표시

2026-09-13 확인. 공식 문서: https://www.youthcenter.go.kr/cmnFooter/openapiIntro/oaiDoc

청년정책API(getPlcy) 요청 항목은 apiKeyNm, pageNum, pageSize, pageType, plcyNo, rtnType, plcyKywdNm, plcyExplnCn, plcyNm, zipCd, lclsfNm, mclsfNm이다. 신청 날짜 필터와 정렬 옵션은 문서에 없다. 미지원 파라미터는 보내지 않는다.

응답의 aplyYmd를 한국 시간 기준으로 검증한다. 신청 중인 후보만 모델과 화면에 전달하고 신청 시작일 내림차순으로 정렬한다. 마감·예정·기간 미확인은 제외한다. 사업 기간과 등록일을 신청 기간으로 대체하지 않는다. 신청 기간에 포함돼도 개인 신청 자격이나 예산 잔여를 보장하지 않는다.

기본 3페이지 뒤에도 지역이 맞는 접수 중 후보가 없으면 시간 한도 내 최대 6페이지까지 확인한다. 전체 API 데이터의 최신순을 보장하는 것이 아니라 조회한 후보 안에서 정렬한다. 빈 결과는 조회 범위에서 찾지 못했다고 안내한다.

## 지역 범위 통합

region_codes.json은 온통청년 getCtpvCd 및 getSggCd 공식 응답을 2026-09-13에 수집한 목록이다. 일반구가 있는 상위 시는 하위 지역 명칭과 법정 코드 계층으로 묶었다. 배포 시 이 파일을 policy_fetch.py와 함께 포함해야 한다.

광역 선택은 하위 시군구 전체와 상위 광역 코드를 API zipCd 목록에 함께 전달한다. 특정 기초 지역 선택은 이웃 구로 넓히지 않고 상위 시·도를 포함한다. 무필터 조회 결과도 합쳐 중복 제거한다. 전국 공통은 공식 하위 지역 전체 또는 광역 코드 전체를 포함한 경우만 표시하며 코드 누락은 지역 확인 필요로 남긴다. 최신 행정구역과 과거 정책 코드가 다르면 전국 여부를 보수적으로 표시한다.

정책 카드에는 _regionScope.label을 표시하고 접수 중 후보는 최대 12건 표시한다. 지역 일치는 개인 신청 자격 보장이 아니다.
